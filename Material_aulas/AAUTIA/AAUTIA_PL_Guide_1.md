## 2. Datasets before Models

Before starting to train machine learning models, it is essential to first obtain high-quality data. You should combine multiple smaller datasets to create a final dataset that is larger and more reliable.

The raw data can be in any format, such as images, text, audio, or even time series. To use it as input for a model, everything must be converted into a **tabular data format**, where the samples (rows) can have many features (columns). Therefore, a model will learn to automatically output a prediction for each sample, based on the statistical properties of its features.

> **Important:** Remember to carefully analyze the noise and outlier values of each feature, to ensure that you only use clean, realistic, and unbiased data.

You should start your search in the following repositories:

a. **EU Open Data Portal** ([https://data.europa.eu/](https://data.europa.eu/))  
b. **Zenodo** ([https://zenodo.org/](https://zenodo.org/))  
c. **IEEE DataPort** ([https://ieee-dataport.org/](https://ieee-dataport.org/))  
d. **Kaggle** ([https://www.kaggle.com/datasets](https://www.kaggle.com/datasets))  
e. **GitHub** ([https://github.com/awesomedata/awesome-public-datasets](https://github.com/awesomedata/awesome-public-datasets))
